Majesta One is a dedicated install, not a multi-tenant SaaS login. Pick a path, pin the image digest you intend to run, then [connect](/connect).

- **Path A** — DigitalOcean App Platform (first targeted managed install).
- **Path B** — Compose for local/dev, or Helm on Kubernetes.

Do not treat Control IDE as the installer. Builders use MCP + `one` after the API is up.
