Majesta One is a dedicated install, not a multi-tenant SaaS login. The illustrated DigitalOcean path, including Control IDE, is [Set up](/setup). This page is the operator reference for both install paths. Pin the image digest you intend to run, then [connect](/connect).

- **Path A** — DigitalOcean App Platform. Follow [Set up](/setup).
- **Path B** — Compose for local/dev, or Helm on Kubernetes.

Do not treat Control IDE as the installer. It connects to an install that is already up. Builders can use MCP + `one` instead.
