Once an install is running, operators and builders talk to it over **MCP + `one` + family HTTP**. Send `Authorization: Bearer` with a JWT from that install.

Control IDE is an optional desktop JWT client. It is not required to install, ship metadata, or run agents.

SCIM and MCP routes belong here, not on a separate “IDE” host.
