Metadata shapes **this** install: objects, fields, rules, automations, permission-set definitions, and packages. Call `/metadata/v1` with scope `metadata`. Writes apply only to the install that receives the request. It does not CRUD business records or roll product images.

Managed vs custom: [customization](/customization). Catalog: [objects](/objects). Overview: [API families](/api/families).
