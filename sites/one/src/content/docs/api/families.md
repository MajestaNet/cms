Every Majesta One install exposes five versioned HTTP families. Pick the family that matches the work, then call it with a credential that carries that scope. Endpoint lists live on each family page. Do not treat `GET /client/v1/describe` as a public catalog.

[Client](/api/client) · [Metadata](/api/metadata) · [Deploy](/api/deploy) · [Ops](/api/ops) · [Auth](/api/auth). Pin `One-API-Revision` on [revision](/api/revision). Managed objects: [objects](/objects).
