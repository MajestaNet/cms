# Brand assets

Copies of the August 2026 Majesta.Net identity from [`MajestaNet/webpage`](https://github.com/MajestaNet/webpage) (`public/brand/`).

**These files are trademarks, not Apache-2.0.** See [NOTICE](../NOTICE) and [BRAND.md](../BRAND.md). Use them on Majesta public docs sites. Do not type the wordmark; use the SVG lockups.

| File | Use |
|---|---|
| `logo-gold.svg` | Primary lockup on navy |
| `logo-navy.svg` | Lockup on ivory / light docs chrome |
| `logo.svg` | `currentColor` lockup |
| `symbol-gold.svg` / `symbol-navy.svg` | Globe only |
| `symbol/gold-*.png` | Profile / touch icons (transparent gold globe) |

`logo-white.svg`, `logo-ivory.svg`, `logo-black.svg`, `logo-reversed.svg`, and `logo-two-colour.svg` are the rest of the lockup set from the website. Prefer gold-on-navy or navy-on-ivory for docs.

When Starlight is scaffolded, copy the files this site actually serves into that site’s `public/brand/` (or equivalent). Keep this directory as the vendor original.
